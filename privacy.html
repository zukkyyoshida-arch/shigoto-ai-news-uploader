プライバシーポリシー

shigoto-ai-news uploader（以下「本ツール」）は、YouTubeチャンネル「しごとAIニュース」の運営者が、自分のチャンネルへ動画をアップロードするためだけに使うツールです。

取得する情報

本ツールは Google の OAuth を通じて、YouTube Data API の次の権限を使います。

  • youtube.upload：運営者のチャンネルへ動画をアップロードするため
  • youtube.readonly：アップロード先が正しいチャンネルかを確かめるため

情報の使い方と保管

取得した認証情報は運営者の管理するコンピューター内にだけ保存し、上記の目的以外には使いません。第三者への提供・販売はしません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Limited Use 要件を含む Google API Services User Data Policy に従います。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

お問い合わせ

YouTubeチャンネル「しごとAIニュース」までお願いします。
